# Google Antigravity основи

## Короткий зміст
Платформа агентної розробки: агент складає Implementation Plan, вносить зміни (diff) і формує Walkthrough.

## Основні твердження
- Editor View — робота з кодом; Manager Surface — керування агентами.
- Local Mode працює в поточній папці, New Worktree Mode — в окремому Git-worktree.
- Workspace skill лежить у `.agents/skills/<назва>/SKILL.md`.
- Відповідальність за результат несе студент, а не агент.
