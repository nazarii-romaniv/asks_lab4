# Метод PARA

## Короткий зміст
PARA ділить знання на Projects (активні результати з дедлайном), Areas (довготривалі сфери), Resources (тематичні матеріали) та Archives (неактивне). Inbox — тимчасове місце для нових нотаток.

## Основні твердження
- Projects мають кінець, Areas — ні.
- Inbox відокремлено, щоб не змішувати необроблене з перевіреним.
