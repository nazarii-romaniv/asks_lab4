# Markdown та YAML frontmatter

## Короткий зміст
Markdown — простий текстовий формат; YAML frontmatter — блок метаданих між рядками `---` на початку файлу.

## Основні твердження
- Текстові файли читаються без спеціальних програм і добре працюють з Git.
- Метадані: `title`, `created`, `updated`, `type`, `status`, `tags`.
- Зв’язки між нотатками записуються як `[[Назва нотатки]]`.
