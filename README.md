# Second Brain (agy-lab4-second-brain)

Локальний персональний Second Brain: Markdown-нотатки за моделлю PARA, вебінтерфейс для перегляду/пошуку/фільтрації за тегами та workspace-навичка для AI-агента.
Лабораторна робота №4, «Архітектура спеціалізованих комп’ютерних систем», Національний університет «Львівська політехніка».

Автор: Романів Назарій Романович, КІ-407, варіант 19.

## Запуск

Потрібен Node.js ≥ 20. Залежностей немає, `npm install` не потрібен.

```bash
npm start            # http://127.0.0.1:3000
PORT=4000 npm start  # інший порт
npm test             # автоматичні тести
```

## Можливості
- створення та редагування Markdown-нотаток (поля `title, created, updated, type, status, tags, source`);
- категорії Inbox / Projects / Areas / Resources / Archives;
- пошук за словом (назва, теги, текст) і фільтр за тегом;
- внутрішні посилання `[[Назва нотатки]]`, зворотні посилання, підсвічування зламаних посилань;
- повна локальна робота, без зовнішніх API.

## Архітектура
```
Браузер (src/public) ⇄ HTTP JSON API (src/server.js) ⇄ ядро (src/notes.js) ⇄ notes/*.md
```
Детально: [docs/architecture.md](docs/architecture.md). Хмарний варіант (проєктне рішення): [docs/cloud-design.md](docs/cloud-design.md).

Структура:
```
.agents/skills/second-brain/SKILL.md   навичка агента
notes/{Inbox,Projects,Areas,Resources,Archives}/
templates/note-template.md
src/    server.js, notes.js, public/
tests/  notes.test.js, repo-notes.test.js
docs/   architecture.md, cloud-design.md
```

## Обмеження
- один користувач, без автентифікації; сервер слухає лише `127.0.0.1`;
- пошук — простий підрядковий, без ранжування й морфології;
- мінімальний YAML-парсер (рядки, `[списки]`); вкладені структури не підтримуються;
- Markdown-рендер спрощений (заголовки, списки, `код`, **жирний**, `[[посилання]]`);
- при одночасному редагуванні двома вкладками виграє останній запис.

## Політика приватності
- Усі дані зберігаються лише у файлах `notes/` на вашому комп’ютері; застосунок не робить мережевих запитів.
- У репозиторій не комітяться паролі, токени, медичні, фінансові та інші чутливі дані (`.gitignore` виключає `.env`, ключі, `backups/`).
- Нотатки не передаються зовнішнім сервісам. AI-агент працює лише з файлами цього проєкту; видалення/переміщення файлів — тільки після підтвердження.
- Git не замінює резервну копію: робіть окрему копію папки `notes/` на інший носій.
